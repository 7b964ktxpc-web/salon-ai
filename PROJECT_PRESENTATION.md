# Паспорт проекта и презентация для заказчика: Студия Lashm.anya

**Заказчик:** Студия наращивания и ламинирования ресниц Lashm.anya (г. Новосибирск, ул. Киевская, 27, офис 48)  
**Продукт:** Комплексная система автоматизации (Умный AI-администратор Telegram + Telegram Mini App для клиентов + защищённая CRM-панель мастера)  
**Статус готовности:** 100% (Production Ready)  

---

## 1. Резюме проекта (Executive Summary)

Для студии **Lashm.anya** разработано и запущено индивидуальное программное решение, полностью закрывающее цикл работы с клиентками в мессенджере Telegram:
1. **Первичный контакт и консультация 24/7** без задержек и ожидания ответа мастера.
2. **Мгновенная онлайн-запись** в пару касаний без переписок с подбором времени.
3. **Автоматическое удержание и программа лояльности** (скидки на День рождения, напоминания за 24 ч / 2 ч, повторный возврат через 28 дней).
4. **CRM-панель мастера**, доступная с любого устройства с авторизацией по Telegram ID.

---

## 2. Ключевые модули экосистемы

### 🤖 Модуль 1: Экспертный AI-Консультант в Telegram
- **База знаний:** обучен на специфике lash-студии (эффекты: натуральный, лисий, кукольный, мокрый, лучики, ламинирование; изгибы: C, D, L, M; толщина: 0.07–0.12 мм).
- **Контекстная память клиенток:** помнит индивидуальные особенности (ношение контактных линз, чувствительность к клею, любимый эффект прошлого визита).
- **Распознавание естественной речи:** клиентка может написать «запиши на пятницу вечер как в прошлый раз», и бот точно сформирует бронирование.
- **Маршрут и навигация:** отправляет точный адрес, ориентиры входа и ссылку на 2ГИС (оценка 5.0).

### 📱 Модуль 2: Клиентский Telegram Mini App
- **Главный экран:** отображает статус ближайшего визита, имя клиентки, статус скидки на День рождения.
- **Каталог услуг:** актуальные цены, длительность и подробное описание процедур.
- **Интерактивный календарь:** выбор свободных временных окон в режиме реального времени.
- **Памятка по уходу:** экспертные рекомендации по уходу за ресницами в первые 24 часа и на каждый день.
- **Профиль лояльности:** форма с указанием даты рождения и начислением скидки 20% (промокод `BIRTHDAY20`).

### 💼 Модуль 3: CRM-Панель Мастера (`/admin`)
- **Безопасность:** вход строго по подтверждённому Telegram ID мастера.
- **Расписание:** наглядный обзор записей на сегодня, завтра и календарь на неделю.
- **База клиентов:** карточки с историей посещений, заметками о любимых эффектах и контактными данными.
- **Триггерные Telegram-уведомления:** ручная и автоматическая отправка напоминаний и поздравлений с ДР в 1 клик.
- **Управление студией:** изменение списка услуг, цен, длительности и рабочих часов.

## 4. Чек-лист для запуска студией

1. **Telegram Bot Token:** Получить токен бота в `@BotFather` и внести в `.env`.
2. **Telegram ID мастера:** Указать ваш Telegram ID в настройках студии для доступа к CRM-панели.
3. **Кнопка в Telegram:** В `@BotFather` включить *Menu Button (WebApp)* для прямого запуска Mini App.
4. **Готово к приёму клиенток!**
